# HealthifyMe: AI Dietician System

A full-stack diet planner and wellness tracking web app inspired by the original HealthifyMe platform. Built with **React**, **FastAPI**, and **Firebase**, this app allows users to manage their meals, track calorie intake, and monitor their health through an intuitive dashboard.

## 🚀 Features

- 🔐 **User Authentication** (Firebase)
- 🥗 **Daily Meal Logging** with Calorie Tracking
- 📊 **Dashboard** for Progress Monitoring
- ⚙️ **FastAPI Backend** with RESTful API
- 💾 **Firestore Integration** for Persistent Data
- 🎨 **Responsive UI** built with React and Tailwind CSS
- ☁️ **Hosting on Render.com** (Frontend + Backend)
